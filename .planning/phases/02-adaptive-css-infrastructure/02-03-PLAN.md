# Research guidance from 02-RESEARCH.md

**Pattern 1: Tailwind CSS v4.1 Native Pointer Variants**
```css
/* Touch device sizing */
<button class="pointer-coarse:h-14 pointer-coarse:px-6 pointer-coarse:text-lg">
  Touch-optimized
</button>

/* Mouse device sizing */
<button class="pointer-fine:h-10 pointer-fine:px-4 pointer-fine:text-base">
  Mouse-optimized
</button>
```

**Pattern 2: Hover Guard Usage**
```css
<button class="
  bg-blue-500
  hover-capable:bg-blue-600     /* Only applies on devices with hover */
">
  Save
</button>
```

# CLAUDE.md requirements
- **Buttons:** Minimum `h-14` (56px) for primary actions (Save, Photo, Add)
- **Inputs:** Minimum `min-h-12` (48px) with `text-base` or `text-lg`
- **Touch targets:** Minimum 44px x 44px

# Phase requirements from ROADMAP.md

- **ADAP-02:** Context-aware sizing (56px buttons for touch, normal size for mouse)
- **ANTI-01:** No hover state pollution on touch devices
