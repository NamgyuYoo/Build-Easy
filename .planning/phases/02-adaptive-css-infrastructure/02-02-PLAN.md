# Research guidance from 02-RESEARCH.md

**Pattern 2: Custom @custom-variant for Hover Capability**
```css
@custom-variant hover-capable {
  @media (hover: hover) {
    &:hover {
      @slot;
    }
  }
}
```

**Pattern 3: Minimum Touch Target Enforcement with CSS Custom Properties**
```css
@layer components {
  .touch-safe {
    min-height: 44px;
    min-width: 44px;
    &.h-8, &.h-9, &.h-10 {
      min-height: 44px !important;
    }
  }

  .touch-primary {
    min-height: 56px;
    min-width: 56px;
  }

  .input-safe {
    min-height: 48px;
  }
}
```

# Phase requirements from ROADMAP.md
- **ANTI-01:** No hover state pollution on touch devices (use `@media (hover: hover)`)
- **ANTI-02:** No shrinking touch targets below 44px/56px for aesthetics
- **RESP-04:** Construction-optimized layout with large touch targets

# CLAUDE.md requirements
- Buttons: Minimum `h-14` (56px) for primary actions (Save, Photo, Add)
- Inputs: Minimum `min-h-12` (48px) with `text-base` or `text-lg`
- Touch targets: Minimum 44px x 44px
